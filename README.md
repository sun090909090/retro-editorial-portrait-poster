# Retro Editorial Portrait Poster

一个用于 Codex 的人物海报设计 Skill，可将人物照片重新设计为复古 Editorial 杂志拼贴风格。

视觉方向包含 70s–90s 欧美杂志、电影宣传册、独立出版物、Halftone、Offset Print、Xerox 与 Cutout Collage。

## 安装

将本仓库复制到 Codex skills 目录：

```bash
git clone <repository-url> ~/.codex/skills/retro-editorial-portrait-poster
```

安装完成后，在下一轮对话中即可使用。

## 使用

上传一张人物照片，然后提出类似请求：

> 把这张照片做成复古 Editorial 杂志拼贴人物海报，主标题叫「今日 OOTD」。

详细规则与提示词模板请查看 [SKILL.md](./SKILL.md)。

## 文件

- `SKILL.md`：Skill 定义、触发条件、设计规范与提示词模板。
